Graviton Librarian

Manage your Graviton M1 and M2 backups

Browse, rename, reorder, copy and clear presets, songs, setlists and SysEx slots. Pull items from another backup of the same model by dragging them across. The model (M1 or M2) is detected automatically; use the Model menu at the top to force it.

Everything runs locally in your browser. Only the slots you change are rewritten; every other byte of the file is kept exactly as it was.

Before you start: keep your original .bak and try edits on one backup slot first. This is an unofficial tool, so see About for what has been tested.

You're using the web version. Browsers block web pages from reaching the unit, so Get from device and Send to device are off here. Download this page and open the file on your computer to use them.
